# Critérios de contexto mínimo

Um engajamento está pronto para trabalho quando contém:

- pergunta decisória em uma frase;
- situação, complicação e questão;
- critério de sucesso e prazo;
- owner/patrocinador ou `[a confirmar]`;
- restrições conhecidas;
- hipótese inicial contestável;
- inventário de dados com fonte/status;
- premissas explícitas;
- próximo passo.

Não é necessário preencher todos os detalhes para começar. É necessário distinguir vazio, desconhecido e confirmado.
