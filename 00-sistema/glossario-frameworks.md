# Glossário de Frameworks (PT-BR)

Os 50+ frameworks disponíveis, com o nome em inglês (como aparecem na skill), para que servem, e onde estão. Os arquivos ficam em `.claude/skills/consulting/`.

## Quando usar o quê — atalho

| Sua pergunta | Frameworks |
|--------------|------------|
| "Preciso estruturar um problema complexo" | McKinsey 7-Step + MECE + Issue Tree |
| "Preciso estruturar uma apresentação" | Pyramid Principle + SCQ + Storyboarding |
| "Como está esse mercado / essa empresa?" | PESTEL → Porter's 5 Forces → SWOT → 3C |
| "Por onde crescer?" | Ansoff + GE-McKinsey + BCG Matrix |
| "Por que o lucro caiu?" | Profitability Framework |
| "Qual o tamanho desse mercado?" | Market Sizing (top-down + bottom-up) |
| "Devemos comprar essa empresa?" | M&A + Due Diligence + Synergy Analysis |
| "Que preço cobrar?" | Pricing Framework |
| "Devemos entrar nesse mercado?" | Market Entry + 5 Forces + Profitability |
| "Estou desenhando um produto/negócio novo" | Business Model Canvas + Design Thinking + Customer Journey |
| "Estou tocando um projeto" | WBS + RACI + Risk Matrix + Stakeholder Analysis |
| "Preciso conduzir uma mudança organizacional" | Kotter's 8 Steps + ADKAR + Stakeholder Analysis |
| "Preciso definir metas e medir" | OKRs + Balanced Scorecard |
| "Vale a pena esse investimento?" | NPV + IRR + Payback + Sensitivity Analysis |
| "Esse cliente dá lucro?" | Unit Economics (LTV/CAC) + Break-even |
| "Preciso melhorar a operação" | Process Mapping + Root Cause + Lean + Six Sigma |

## Problem-solving — `problem-solving.md`

| Framework | Em português | Para quê |
|-----------|--------------|----------|
| MECE | Mutuamente exclusivo, coletivamente exaustivo | Quebrar um problema sem sobreposição e sem lacuna |
| Pyramid Principle | Princípio da Pirâmide | Comunicar resposta primeiro, argumentos depois |
| Issue Tree | Árvore de questões | Decompor a pergunta em sub-perguntas testáveis |
| Hypothesis Tree | Árvore de hipóteses | Testar teorias em vez de coletar dados sem foco |
| McKinsey 7-Step | Processo de 7 passos | Fluxo completo de resolução de problema |
| SCQ | Situação–Complicação–Questão | Enquadrar o problema antes de resolvê-lo |
| Storyboarding | Storyboard / ghost deck | Desenhar o entregável antes de fazer a análise |
| 80/20 (Pareto) | Regra 80/20 | Priorizar os poucos ramos que explicam o resultado |
